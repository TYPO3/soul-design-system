Every actions-* icon in @typo3/icons ships — a sample is shown. The identifiers are the core’s own — actions-search, actions-code-compare — so an agent resolving one through typo3_icon_lookup gets the same name the design uses, and the first segment is the path: src/actions/actions-search.svg, in the package or under cdn.jsdelivr.net/npm/@typo3/icons@5.0.3/src/. Anything outside the shipped categories is fetched from there — never drawn locally, never taken from another set. Missing upstream too, it is contributed to TYPO3/TYPO3.Icons.
