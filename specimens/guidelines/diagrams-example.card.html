One file, both modes. Every colour is an attribute written as var(--token, #light), so the drawing takes the mode of the page it is referenced into and still renders on its own — in a README or a tab — as the light file it falls back to. What it cannot be is an <img>: that renders in a document of its own, where no token is declared.
