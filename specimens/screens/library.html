One mark per thing the backend does

Search by what the thing does, not by what it looks like. Every drawing is indexed by purpose as well as by name, so bin finds actions-delete.

What the set is

Four figures rather than four adjectives. Every one of them is a count somebody can arrive at from the catalogue, which is the difference between a fact and a claim wearing a number.

392
glyphs
Every one of them drawn on the same 16 × 16 canvas, at one stroke weight.
4
releases answered for
12.4, 13.4, 14.3 and main. Each glyph says which of them it holds for.
0
dependencies
One sprite per category and a stylesheet. Nothing to install to read a name.

From the bundled index, with nothing booted and no request leaving the machine.
