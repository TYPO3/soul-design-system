What a degraded source costs you

A tool that declared it falls back to the next source it declared and says so in the result. Nothing waits, nothing retries silently, and no answer arrives without the substitution named in it.

What a source is Report a wrong answer
docs.typo3.org is answering slowly
Documentation lookups take about 2.4 s instead of 300 ms. Every other tool is unaffected: nothing else on this list reads from it.
releases.typo3.org is unreachable from the checker
Version discovery falls back to what the installation itself declares, which is the release you are running rather than the newest one that exists.

What this page is not

It is one location asking, every five minutes
A source that answers here may be unreachable from your network, and the reverse. The tool’s own result is the authority for the machine it ran on — this page is a hint about the sources, not a verdict.
There is no incident history, because there is no service
Nothing is hosted for you to depend on. What would be an outage elsewhere is a degraded answer here, and the answer says so at the moment it is given.
