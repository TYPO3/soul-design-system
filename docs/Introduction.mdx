# TYPO3 Support App — design system

Tokens, one component class layer, seven Lit elements, and 38 specimen cards
that document them.

The system is **CSS first**. `styles.css` is the whole contract: link it, put
`sds-app` on the root element, and put `sds-` classes on markup. That is what
the product — a local MCP server written in plain PHP — actually consumes, and
it needs no JavaScript to do it.

The Lit elements in `src/` render **light DOM** and emit exactly those
classes. They are a convenience for surfaces that already run JavaScript, not
a second styling system: `components.css` stays the single source of truth,
and a component and a hand-written `<button class="sds-btn">` are styled by
the same rules.

## Where things live

| | |
| --- | --- |
| `styles.css` | the single entry point — tokens, then the component layer |
| `tokens/*.css` | colour, type, control scale, spacing, radius, motion |
| `components.css` | the `sds-` class vocabulary every surface is built from |
| `src/*.ts` | the Lit elements and their template functions |
| `stories/*.stories.ts` | these pages, and the specimen each card is generated from |
| `guidelines/*.card.html` | the token-layer specimens, embedded in Guidelines |
| `_specimen.css` | chrome for the cards only, deliberately outside `styles.css` |

## The one direction that matters

Component markup is written once, in `src/`. Storybook renders it, and
`make cards` renders it into the static specimen cards under
`components/`. Those cards are **generated** — edit the story, never the
card.

The guideline specimens are not generated. They document tokens rather than
components, have no props to vary, and are embedded here as they are.

## Non-negotiable

- **One accent.** `--accent` marks exactly three things: the active
  navigation item, the shell prompt in a code block, the pipe in the
  wordmark.
- **No shadows.** Separation is a hairline plus `--surface-overlay`. The
  focus ring is the single `box-shadow` in the system, and it is a state.
- **No emoji.** Status is a colour plus a glyph from `assets/icons/`.
- **Mono is semantic.** Anything the machine reads, writes or names is
  Source Code Pro, verbatim, at every size.
- **16px is the floor** for the signet and the icons.
- **Hover changes colour and border.** Never position, never size.

`SKILL.md` is the operating instruction and `RATIONALE.md` is the reasoning
behind it. Read the second before extending or breaking a rule in the first.
