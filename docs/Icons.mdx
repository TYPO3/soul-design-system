# Icons

33 icons from [TYPO3/TYPO3.Icons](https://github.com/TYPO3/TYPO3.Icons). The
identifiers are the core's own — the same strings `typo3_icon_lookup`
returns — so design and runtime name the same thing.

**Where they come from.** The set is generated, never committed:
`scripts/icons.ts` copies the identifiers it declares out of the
`@typo3/icons` package, which the container installs and its entrypoint
materialises.
An empty `assets/icons/` means `npm ci` has not run; it is not a missing
file to work around.

**Getting one that is not in the 33.** An identifier resolves to a path by
its first segment: `actions-search` → `src/actions/actions-search.svg`. The
package holds 796 icons across 15 categories, plus `dist/icons.json`, which
maps every identifier to its category and the 211 deprecated aliases to
their current names. Resolve an alias before using it — the old spelling is
not what `typo3_icon_lookup` returns.

To *ship* one, add its identifier to the `ICONS` list in
`scripts/icons.ts` and run `make icons`. Never drop a file into the
generated directory by hand.

**A missing icon is contributed upstream**, never drawn locally and never
substituted from another set. The script fails on an identifier the package
does not have, rather than falling back to anything.

## Rules

- 16 × 16 viewBox, filled paths, `fill="currentColor"` at `--text-secondary`.
- Sizes 16, 20, 24 or a whole multiple. **Never 18 or 22.** 16 is the floor;
  below it, no icon at all.
- Icon before its label with an 8px gap — except direction icons, which
  follow.
- Inline the SVG wherever colour must follow the UI. An `<img>` cannot
  inherit `currentColor`, which is why `src/lib/icon.ts` inlines rather than
  links.

Only four icons may stand without a label: `actions-check-circle`
(answered), `actions-exclamation-triangle` (version-bound),
`actions-exclamation-circle` (installation not bootable) and
`actions-info-circle` (a stated boundary).
