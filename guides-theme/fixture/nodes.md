# A second page, so the menu has two of them

The first page is the kitchen sink. This one exists for what only appears once
a project has more than one document: the menu, the breadcrumb, the previous
and next links, and a heading another page can point at.

## A section something links to

A link to [the kitchen sink](index.md) resolves inside the project and is
rendered as a plain link.

## A second section

So the menu has two entries under this page to show, and the layout has a
