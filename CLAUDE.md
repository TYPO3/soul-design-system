# CLAUDE.md

`AGENTS.md` is the instruction for this repository. This file imports it
instead of a pointer to it. An import is in context before the first tool
call. A pointer is a file somebody still has to decide to open. So
everything it says holds here, in one copy, for both readers. Which paths
are source and which are output, the tasks, the gate, what fails review.

Nothing else belongs in this file. A rule here and there drifts on one side
without notice. A rule only Claude can see is one no other reader can
follow or correct. That is what `AGENTS.md` says about agent notes, and it
applies to this file first.
