The tool surface is not stable yet. Names and arguments can change between releases, and the bundled knowledge covers 12.4, 13.4, 14.3 and main only.

It answers before it guesses

A local MCP server in plain PHP for the three audiences that do TYPO3 work. Every answer names the source it came from and the versions it holds for.

Install

The server runs as a subprocess of your client. It needs PHP 8.2 or newer and nothing else — no daemon, no database, no network access unless a tool asks docs.typo3.org for a page.

bash copy 
# standalone: clone, install once
$ composer install
$ vendor/bin/typo3-support-app install
